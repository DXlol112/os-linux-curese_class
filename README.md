# Курс по операционным системам Linux

## О чём этот репозиторий

Здесь будут храниться материалы курса по операционным системам Linux. В репозитории будут находиться отчёты, скриншоты, скрипты и другие материалы, которые будут на курсе.

### Цель курса

1. Научиться работать с Linux-средами, включая командную строку, терминалы и графические интерфейсы.
2. Научиться использовать инструменты для мониторинга и управления системой, включая процессы, память, диски и сеть.
3. Научиться использовать инструменты для виртуализации и контейнеризации, включая WSL, Docker и другие.
4. Научиться находить и исправлять ошибки в работе системы, включая проблемы с производительностью, совместимостью и безопасностью.

Одна работа — отдельная папка, понятные имена файлов, осмысленные коммиты, отсутствие секретов и персональных данных.


### Личные ожидания от курса
Надеюсь, что курс поможет мне лучше понять операционные системы Linux, научиться использовать их в повседневной работе и развить навыки программирования и администрирования. Я хочу научиться эффективно использовать командную строку, работать с процессами и памятью, а также разбираться в виртуализации и контейнеризации. Что в дальнейше может пригодится для адаптации в Linux-средах, а также для работы с облачными сервисами.
