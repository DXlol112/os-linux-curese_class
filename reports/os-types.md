## Задание 2. Сравнение операционных систем

| ОС | Где используется | Тип | Задачи | Интерфейс | Главное отличие |
| :-- | :-- | :-- | :-- | :-- | :-- |
| Windows 11 Pro | ПК и ноутбуки | Настольная | Много задач | GUI и CLI | Подходит для повседневной работы и программирования. |
| Ubuntu Desktop | ПК и ноутбуки | Настольная Linux | Много задач | GUI и терминал | Открытый исходный код и удобная работа с Linux. |
| Android | Смартфоны и планшеты | Мобильная | Много задач | Сенсорный GUI | Создана для мобильных устройств и приложений. |
| FreeRTOS | Микроконтроллеры и IoT | ОС реального времени | Несколько задач | Обычно без общего GUI | Быстро выполняет задачи управления устройством. |

Все операционные системы созданы для разных задач. Windows и Ubuntu подходят для обычных компьютеров. Android используется на мобильных устройствах. FreeRTOS нужна для управления электроникой и работы в реальном времени. Поэтому выбор ОС зависит от устройства и цели использования.
