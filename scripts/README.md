# Скрипты

## Что здесь будет

Эта папка будет использоваться для хранения системных скриптов.

1. Скрипты автоматизации, которые помогут в работе с Linux-средами.

2. Скрипты для сбора информации о системе, которые помогут в создании системного паспорта.

3. Скрипты для установки и настройки программного обеспечения.
