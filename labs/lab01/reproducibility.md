# Как повторить диагностику

## Шаги

1. `Win + R` → ввести `winver` → найти редакцию, версию и сборку Windows → сверить с `01_winver.png`.
2. `Win + I` → **Система** → **О системе** → найти CPU, RAM, тип системы и Windows → сверить с `02_about.png`.
3. `Ctrl + Shift + Esc` → **Производительность** → **ЦП** → найти модель, ядра, потоки и виртуализацию → сверить с `03_cpu.png`.
4. Диспетчер задач → **Производительность** → **Память** → найти общий и занятый объём → сверить с `04_memory.png`.
5. Диспетчер задач → **Производительность** → **Диск 0** → найти модель, тип, объём и активность → сверить с `05_disk.png`.
6. Диспетчер задач → **Производительность** → **GPU** → найти модель, загрузку и видеопамять → сверить с `06_gpu.png`.
7. Диспетчер задач → **Процессы** → выбрать 3 процесса → записать CPU и память → сверить с `07_processes.png`.
8. `Win + R` → ввести `msinfo32` → найти Windows, CPU, RAM, BIOS и тип системы → сверить с `08_msinfo32.png`.
9. `winver` и `msinfo32` → сравнить Windows → Параметры и Диспетчер задач → сравнить CPU и RAM.
10. Скрыть личные данные → сохранить скриншоты под именами `01–08` → проверить их открытие в Markdown.

## Выполненные команды

```powershell
cmd /c ver
Get-Process
(Get-LocalUser -ErrorAction SilentlyContinue | Measure-Object).Count
Get-Service -Name 'Dhcp','Dnscache','NlaSvc' | Select-Object Name,Status
code --version
py --version
```

Команды не выводят пароли, IP, MAC и серийные номера.
